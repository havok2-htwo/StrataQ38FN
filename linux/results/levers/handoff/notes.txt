Change (src/prefill/prefill.cpp, include/strata/prefill/prefill.hpp):
  sender: event "work done" + P D2H pieces into the existing pinned hand-off buffer, an event after each; the host waits
  only for "work done" (what on_stage_chunk's checkpoint parts / the error check need), then starts the next stage.
  receiver: per piece cudaStreamWaitEvent(cross-device) + H2D of that piece on its prompt stream (a smaller receiver chunk:
  wait all, one copy). Next stage's chunk runs on one persistent, once-pinned worker thread (packaged_task futures, same
  results/exceptions) instead of std::async's thread per chunk (~1-1.4 ms thread start measured in nsys).
  STRATA_HANDOFF_PIPE_WORKER=0 = pieces without the worker (A/B only).
Cost: VRAM 0 (free-VRAM trace lines within +-4 MiB of the reference, driver noise). Host: no new pinned memory (the two
