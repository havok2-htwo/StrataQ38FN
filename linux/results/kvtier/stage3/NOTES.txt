What it does (critique order 3a + 3c; 3b as "keep the old file, read the suffix")
- ConversationCache::evict_oldest(spill) + an eviction sink.  Only make_room's evictions (budget / slots) spill; the RAM
  floor's and a save's evictions free at once (counted drops_ram); drop_superseded and clear() never reach the sink.
- Spill: >= STRATA_CONV_TIER_MIN_TOKENS (16384), day budget left, in-flight bound; queued to one writer thread, which
  writes each stage's image as a plain v1 session file (O_DIRECT, temp + fsync + rename + dir fsync), the 4 stages at
  once, then <key>.meta as the commit record (ids, checkpoint lengths, marks pinned/slot_turn/draftless).  RAM freed
  after the write.  A set without meta is never used and removed at the next start (as are temp files).
- Write once: an image a file holds all but < STRATA_CONV_TIER_REGROW_TOKENS (8192) of, or an earlier copy of a
  conversation on disk, is not written ("kept"); the request restores the file and reads the suffix.  Grown further:
  written in full, the older set removed ("superseded").
- Restore (request start, before any park): the tier's best match must beat RAM cache / slot / live by
  STRATA_CONV_TIER_MIN_GAIN (2048); 4 parallel reads with per-stage read limits (new draft-pointer overload) and the
  RAM preflight, consistency against the meta, marks restored, then the normal validation; an image still queued is
  handed back without a read.  Any failure (I/O, checksum, identity, RAM) -> miss, prompt read instead.
- Budget per local calendar day (STRATA_CONV_TIER_WRITE_GB_DAY 200, <dir>/budget, survives restarts); cap
  STRATA_CONV_TIER_CAP_GB 600 / MAX_FILES 2000 (LRU), TTL_H 168 by last use; INFLIGHT_MIB 2048; MIN_FREE_GB 64.
- Identity: session identity (model + config fp) mixed with the engine binary (/proc/self/exe), argv and the sorted
  STRATA_* env (STRATA_CONV_TIER_* excluded), in every file header and the meta.  WARM unset: the folder is emptied at
  start; STRATA_CONV_TIER_WARM=1 indexes this engine's sets, keeps other identities until their TTL.
- STRATA_CONV_TIER_VERIFY=1: each written part read back and compared (same_part); each restore checked against a
  digest of the evicted image (conversation_image_digest).  #879 clears the tier.
- Status: every event logs "conversation tier: <event>; files= parts= disk_bytes= written_today= budget= budget_left=
  spills= written_bytes= restores= restores_queue= read_bytes= misses= drops_small= drops_budget= drops_busy=
  drops_ram= drops_cap= drops_io= kept= superseded= expired= evicted= pending= pending_bytes= foreign= verified=";
  server.py ConvCacheLog -> GET /metrics conversation_cache.tier (absent without the tier).

Recommended default: T16-143-64khocast (tier on, default knobs, WARM unset).  Zero cost while RAM holds everything
(A/B 0.00 %, inert without evictions), +25 % tok/s in RAM overflow; 200 GB/day caps the SSD wear (~73 TB/year worst
case).  MIN_TOKENS 16384 / REGROW 8192 / MIN_GAIN 2048 as defaults; WARM=1 works (tested) but see open points.

Open points
- Foreign-identity files under WARM=1 are kept until their TTL and not counted against the cap/max_files (only
  reported as foreign); a shared folder for A/B arms should stay WARM unset (emptied at start).
- File deletions (supersede/expire/cap) run under the tier lock on the writer thread; a request's best() waits for
  them (ext4 unlink of ~150 MB parts, not measured separately; no stall visible in the runs).
- "kept" restores an older file and re-reads up to REGROW_TOKENS - 1 tokens; no delta files (critique 3b) yet.
- A write fault at SessionWriteOptions level is only injected at the first full 16 MiB block (small files skip it);
  the tests use a > 16 MiB image for that step.
- SYCL: not built here (its generate.cpp does not use the tier; the shared headers compile unchanged by default).
  HIP: no CUDA API in the new code; not built here.
- Test artefacts: /media/raid0/strata-kvspill was removed after the runs (incl. its budget file).
