KV tiering stage 1: asynchronous parking (STRATA_PARK_ASYNC=1), 2026-10-12
Code: Strata-143 g3-143 ff1b3b04 (on 1797c0fb), build-143, engine/strata-g3-143kt.  Config with the switch:
linux/configs/T16-143-64khoca.json (= T16-143-64khoc + STRATA_PARK_ASYNC=1, exe 143kt).

What it does
- After a request (DONE/BADM) the main sessions' conversation is captured on 4 persistent threads (one per stage
  device) while the slots decode: devices synchronized once at start (no group running yet), then only private-stream
  copies through 2 x 16 MiB pinned staging blocks per device (128 MiB pinned), stoppable between blocks.  Checkpoints:
  each stage's split list, copied (conversation_checkpoints_stage_copy).  RAM admission at start never evicts.
- Next request: park decision as before.  Due -> join, superseded drop, make_room, RAM floor (evicting), put.
  Not due -> cancel; a complete capture's K/V pages kept as retained pages (like after a restore).
- Dropped at #879 flush, VRAM, SAVE/RESTORE; elastic K/V (kvg) and groups running past a request keep the sync park.
- Fallback sync park uses STRATA_PARK_THREADS (stages in parallel).  With the switch, retained K/V is dropped before a
  slot give-back (critique A1).  STRATA_PARK_ASYNC_VERIFY=1: sync capture at every park, must be byte-identical.
