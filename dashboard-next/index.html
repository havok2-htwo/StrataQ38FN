aus (sofort antworten)"reasoning_effort": "none"
oder "chat_template_kwargs": {"enable_thinking": false}		"thinking": {"type": "disabled"}
low"reasoning_effort": "low""output_config": {"effort": "low"}
medium"reasoning_effort": "medium""output_config": {"effort": "medium"}
high (Standard)"reasoning_effort": "high" oder weglassen"output_config": {"effort": "high"} oder weglassen

high ist die höchste Stufe und gilt, wenn nichts angegeben ist; ein „xhigh“ gibt es nicht. Auch "reasoning": {"effort": "low"} wird verstanden. Anthropic "thinking": {"type": "enabled", "budget_tokens": N}: unter 2K = low, unter 8K = medium, mehr = high. Harte Obergrenze fürs Denken: "reasoning_budget_tokens": N (danach wird das Denken geschlossen und geantwortet; 0 = keine Grenze). Das Denken kommt als reasoning_content (OpenAI) bzw. thinking-Blöcke (Anthropic).
